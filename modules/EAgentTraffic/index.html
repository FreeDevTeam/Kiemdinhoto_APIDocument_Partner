Partner API Module: EAgentTraffic

Module cung cấp các API kết nối tài khoản đại lý tra cứu giao thông (EAgentTraffic) và tra cứu thông tin phạt nguội phương tiện có hỗ trợ xoay vòng Quota tự động.

Quay về trang chủ | Mở bản Markdown module

Danh sách API

  • 1. Request Login By OTP
    Yêu cầu đăng nhập hoặc gửi mã OTP cho tài khoản đại lý tra cứu giao thông.
    HTML | MD
  • 2. Confirm OTP
    Xác nhận mã OTP để hoàn tất đăng nhập đại lý.
    HTML | MD
  • 3. Request Login By 2FA
    Yêu cầu đăng nhập tài khoản đại lý qua phương thức xác thực hai yếu tố (2FA).
    HTML | MD
  • 4. Confirm Passcode
    Xác nhận mã bảo mật Passcode/PIN của đại lý để cấp token truy cập.
    HTML | MD
  • 5. Lookup Warning For Vehicle
    Tra cứu chi tiết cảnh báo phạt nguội của phương tiện theo biển số và loại phương tiện.
    HTML | MD
