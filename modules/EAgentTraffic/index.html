Partner API Module: EAgentTraffic

Module cung cấp các API xác thực tài khoản đối tác tra cứu thông tin giao thông (EAgentTraffic). Hệ thống hỗ trợ quy trình đăng nhập và xác thực tài khoản đối tác thông qua mã OTP thật gửi về SMS, mã bảo mật Passcode/PIN hoặc phương thức xác thực hai yếu tố (2FA).

Danh sách API

  • 1. Request Login By OTP
    Yêu cầu đăng nhập hoặc gửi mã OTP cho tài khoản đối tác tra cứu giao thông.
    HTML | MD
  • 2. Confirm OTP
    Xác nhận mã OTP để hoàn tất đăng nhập đối tác.
    HTML | MD
  • 3. Request Login By 2FA
    Yêu cầu đăng nhập tài khoản đối tác qua phương thức xác thực hai yếu tố (2FA).
    HTML | MD
  • 4. Confirm Passcode
    Xác nhận mã bảo mật Passcode/PIN của đối tác để cấp token truy cập.
    HTML | MD

Thông tin giả lập (Mock Data & Test Cases)

Dữ liệu giả lập phục vụ kiểm thử tích hợp API (sandbox / test environment). Giúp đối tác kiểm thử các kịch bản thành công và lỗi mô phỏng mà không cần tài khoản thực tế.

1. Yêu cầu đăng nhập bằng OTP (requestLoginByOTP)

Username / CCCD Kịch bản Kết quả giả lập
001200000001 Gửi OTP thành công Thành công – trả về token giả lập và thông báo mã OTP đã được gửi.
999000000001 Tên đăng nhập không hợp lệ Thất bại – INVALID_USERNAME.
999000000002 Không được xác thực Thất bại – AGENTETRAFFIC_UNAUTHORIZED.
999000000003 Lỗi gửi yêu cầu OTP Thất bại – AGENTETRAFFIC_OTP_REQUEST_ERROR.
999000000004 Vượt hạn mức tra cứu Thất bại – AGENT_QUOTA_EXCEEDED.

999000000005 Xác thực thất bại Thất bại – AGENTETRAFFIC_AUTHENTICATION_FAILED.
