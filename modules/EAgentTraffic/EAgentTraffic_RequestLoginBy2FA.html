Partner API - Request Login By 2FA (EAgentTraffic)

Yêu cầu đăng nhập tài khoản đại lý tra cứu thông tin vi phạm giao thông theo phương thức xác thực hai yếu tố (2FA).

Về module EAgentTraffic

Endpoint

URL/ThirdParty/EAgentTraffic/user/requestLoginBy2FA
MethodPOST

Headers schema

HeaderRequiredMô tả
clientId hoặc clientidYesMã định danh đối tác
apiKey hoặc apikeyYesKhóa xác thực API của đối tác

Body schema

FieldTypeRequiredRuleMô tả
usernamestringYesrequired, max 255, alphanumSố CCCD / CMND của tài khoản đại lý tra cứu giao thông.
userDeviceobjectNo-Thông tin thiết bị di động của đại lý / ứng dụng.
userDevice.fingerprintstringNo-Chuỗi nhận dạng hệ điều hành / firmware thiết bị.
userDevice.hardwarestringNo-Mã phần cứng thiết bị (ví dụ: mt6878).
userDevice.brandstringNo-Hãng sản xuất thiết bị (ví dụ: motorola).
userDevice.devicestringNo-Tên thiết bị (ví dụ: aito).
userDevice.modelstringNo-Tên model thiết bị (ví dụ: XT2429-2).
userDevice.manufacturerstringNo-Nhà sản xuất thiết bị (ví dụ: motorola).
userDevice.productstringNo-Tên sản phẩm thương mại của thiết bị (ví dụ: aito_g).
userDevice.bootloaderstringNo-Thông tin bootloader (ví dụ: unknown).
userDevice.sdkVersionnumberNo-Phiên bản Android SDK (ví dụ: 35).
userDevice.gmsVersionstringNo-Phiên bản Google Mobile Services (ví dụ: 262033035).
userDevice.latitudenumberNo-Tọa độ vĩ độ GPS của thiết bị (ví dụ: 12.2702919).
userDevice.longitudenumberNo-Tọa độ kinh độ GPS của thiết bị (ví dụ: 109.2489062).

Sample Request 

curl --location '{HOST_NAME}/ThirdParty/EAgentTraffic/user/requestLoginBy2FA' \
  --header 'Content-Type: application/json' \
  --header 'clientId: TESTCLIENT' \
  --header 'apiKey: 07e73e61-0dce-4b39-8ecf-06ef70b35c08' \
  --data '{
    "username": "001201012345",
    "userDevice": {
      "fingerprint": "motorola/aito_g/aito:15/AP3A.240905.015.A2/1746894222:user/release-keys",
      "hardware": "mt6878",
      "brand": "motorola",
      "device": "aito",
      "model": "XT2429-2",
      "manufacturer": "motorola",
      "product": "aito_g",
      "bootloader": "unknown",
      "sdkVersion": 35,
      "gmsVersion": "262033035",
      "latitude": 12.2702919,
      "longitude": 109.2489062
    }
  }'

Success response

{
  "statusCode": 200,
  "error": null,
  "message": "Success",
  "data": {
    "success": true
  }
}

Mã lỗi

HTTPMã lỗiMô tả
400Validation ErrorPayload không đúng schema (thiếu username, format sai).
429QUOTA_EXCEEDEDapiKey không hợp lệ hoặc đã vượt quá hạn mức gọi API.
500AGENTETRAFFIC_UNAUTHORIZEDKhông có quyền truy cập hoặc tài khoản không được ủy quyền xác thực.
500INVALID_USERNAMESố CCCD / tài khoản đại lý không hợp lệ hoặc không tìm thấy.
500UNKNOWN_ERRORLỗi không xác định.

Tham khảo

  • Quy chuẩn chung → Common Error — danh sách mã lỗi hệ thống trả về trong trường error.
  • Quy chuẩn chung → EAgentTraffic Error Code — danh sách mã lỗi nghiệp vụ đại lý tra cứu giao thông.
